# Asset Mapping

## Resource Directories
- es/drawable/: Sprite sheets, entity icons, item textures, UI frames, XML shapes.
- es/layout/: Android XML layouts using standard View classes and DataBinding <layout> tags.
- es/values/: Strings, colors, styles, dimensions, and ids.xml.
- ssets/: Sound effects (WAV/OGG), font files, and raw game definitions.

## Resource Resolution
- Clean vanilla resources are sourced from C:\Repositories\Idle Guild Master\reference\clean_apk\res.
- Mod-specific strings, drawables, and layouts from the modding repo are NOT imported.
