Dragons Blade II FX — DDS Asset Pack
====================================

This pack contains every DDS supplied in the uploaded DB2Icons.zip and extended assets.
For each DDS, the original atlas is exported losslessly as *_FULL.png.
Transparent DDS atlases additionally have an 'individual' folder with
automatically separated, tightly cropped RGBA PNG regions.

Important: atlas textures are packed sheets, so automated separation can
occasionally split or merge artwork where sprites touch. The *_FULL.png
files are the authoritative source if a crop needs manual adjustment.
